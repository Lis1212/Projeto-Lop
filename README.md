# Projeto Lop
Projeto desenvolvido para estudo de A-Frame (WebVR/3D) e publicação usando GitHub Pages.
A ideia é simular um ambiente de jogo simples com controle de um carro em um cenário 3D.


# Demonstração 
https://lis1212.github.io/Projeto-Lop/


# Funcionalidades 
Controle de objeto (carro) via teclado;
Cena 3D básica com A-Frame;
Interação em VR;
Câmera acompanhando o objeto.


# Tecnologias utilizadas
HTML5;
CSS3;
JavaScript;
A-Frame (framework 3D Web).


# Objetivo do projeto
Aprender desenvolvimento 3D no navegador;
Praticar JavaScript + A-Frame.
